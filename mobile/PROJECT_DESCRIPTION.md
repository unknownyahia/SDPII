# Spots Mobile Project Description

Spots Mobile is a React Native application designed to help people in Qatar discover useful places, local updates, and promoted events around them. The app brings together location-based discovery, community posts, maps, saved places, notifications, profiles, and bilingual English/Arabic support so users can quickly understand what is happening nearby.

The main problem the project addresses is that local information is often scattered across different apps, social media accounts, and personal recommendations. This makes it difficult for residents, students, visitors, and event organizers to find timely, trustworthy, and location-aware suggestions in one place.

Spots solves this by providing a single mobile experience where users can browse trending nearby places, explore updates on a map, filter by category, save favorite spots, publish local updates, and create promoted events. Firebase services support authentication, real-time data, notifications, moderation, analytics, and profile management, while map and location features make the discovery experience more relevant to the user's current area.
